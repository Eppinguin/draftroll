# Draftroll integration examples

These examples use only public package APIs. They intentionally avoid application-specific adapters.

- `framework-free/`: browser SDK session with an accessible text fallback.
- `react/`: generic React provider and hooks.
- `headless/`: server-side rules evaluation without DOM, WebGL, or network access.
- `vtt/`: renderer-independent VTT adapter boundary.
- `bot/`: authoritative room bot connection.
- `stream-overlay/`: transparent overlay controlled by a stream host page.
- `hidden-roll/`: two-browser hidden roll and explicit reveal workflow.
- `cross-origin/`: explicit origin and CSP configuration.
- `custom-symbolic/`: weighted symbolic faces with a supported physical-shell hint and fallback-safe rendering.
